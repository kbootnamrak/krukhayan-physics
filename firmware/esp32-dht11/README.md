# เฟิร์มแวร์ ESP32 + DHT11

อ่านเอกสารออกแบบระบบทั้งหมดได้ที่ [`docs/iot/README.md`](../../docs/iot/README.md)

## เตรียมเครื่องมือ

1. **Arduino IDE** → Preferences → Additional Board Manager URLs ใส่
   `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
2. Boards Manager → ติดตั้ง **esp32 by Espressif Systems**
3. Library Manager → ติดตั้ง **DHT sensor library** (Adafruit) และ **Adafruit Unified Sensor**
4. เลือกบอร์ด **ESP32 Dev Module**, Upload Speed 921600

ถ้าอัปโหลดแล้วค้างที่ `Connecting...` ให้กดปุ่ม **BOOT** บนบอร์ดค้างไว้ตอนเริ่มอัปโหลด

## ตั้งค่า

```bash
cp config.example.h config.h
```

แล้วแก้ `config.h` — อย่างน้อยต้องใส่ `WIFI_SSID`, `WIFI_PASSWORD` และ `DEVICE_KEY`
(ได้จากการกด "เพิ่มอุปกรณ์" ในหน้า `/dashboard/iot` แสดงครั้งเดียว)

`config.h` ถูก `.gitignore` ไว้แล้ว จะไม่ถูก commit

## ใส่ใบรับรองรากเพื่อให้ตรวจ TLS ได้

ค่าเริ่มต้น `ROOT_CA_PEM` เว้นว่างไว้ บอร์ดจะเชื่อมต่อแบบไม่ตรวจใบรับรอง
ใช้ได้ตอนทดสอบ แต่ก่อนติดตั้งใช้งานจริงควรใส่ใบรับรองราก

```bash
openssl s_client -showcerts -connect krukhayan-physics.vercel.app:443 </dev/null
```

คัดลอกใบสุดท้ายในผลลัพธ์ (ใบที่เป็น root CA) รวมบรรทัด `-----BEGIN CERTIFICATE-----`
และ `-----END CERTIFICATE-----` มาวางใน `config.h` แบบนี้

```c
#define ROOT_CA_PEM \
"-----BEGIN CERTIFICATE-----\n" \
"MIIFazCCA1OgAwIBAgIRAIIQz7DSQONZRGPgu2OCiwAwDQYJKoZIhvcNAQELBQAw\n" \
/* ...บรรทัดที่เหลือ... */ \
"-----END CERTIFICATE-----\n"
```

ใบรับรองมีวันหมดอายุ — เมื่อผู้ให้บริการเปลี่ยนใบรับรองราก บอร์ดจะส่งข้อมูลไม่ผ่าน
และต้องแฟลชใหม่ ถ้าไม่สะดวกดูแลระยะยาว การเว้นว่างไว้เป็นทางเลือกที่ยอมรับได้
สำหรับเครือข่ายภายในโรงเรียน

## ไฟสถานะ (LED บนบอร์ด GPIO2)

| รูปแบบ | ความหมาย |
|---|---|
| กะพริบสั้นครั้งเดียว | อ่านและส่งข้อมูลสำเร็จ |
| กะพริบ 3 ครั้ง | ส่งไม่สำเร็จ ข้อมูลถูกเก็บไว้ในบัฟเฟอร์ |
| กะพริบถี่ต่อเนื่อง | กำลังพยายามต่อ Wi-Fi |
| ค้างสว่าง | อ่านค่าจากเซนเซอร์ไม่ได้ ตรวจสายและไฟเลี้ยง |

## พฤติกรรมที่ออกแบบไว้

- **เน็ตหลุด** เก็บค่าไว้ในบัฟเฟอร์วงแหวนได้ 60 ชุด (1 ชั่วโมงที่รอบ 60 วินาที)
  ต่อกลับได้เมื่อไรส่งย้อนหลังทั้งชุด เซิร์ฟเวอร์กันข้อมูลซ้ำให้เอง
- **นาฬิกา** ตั้งจาก NTP เป็นเวลา UTC ถ้าตั้งไม่สำเร็จ เซิร์ฟเวอร์จะใช้เวลาที่รับข้อมูลแทน
- **คีย์ผิด (401/403)** ล้างบัฟเฟอร์ทิ้งเพื่อไม่ให้ตัน เพราะส่งใหม่กี่รอบก็ไม่ผ่าน
- **ส่งไม่สำเร็จเกิน 30 นาที** บอร์ดรีสตาร์ทตัวเองหนึ่งครั้ง
- **รอบการส่ง** เซิร์ฟเวอร์ตอบ `sample_interval_s` กลับมาทุกครั้ง บอร์ดปรับตามโดยไม่ต้องแฟลชใหม่
